An entry for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty: a program that writes
one roast line for a gadget you use every day to `/output/entry.txt`. The line is a fixed,
deterministic string: my noise-cancelling earbuds are so good, the only voice they can't silence is the one whispering 'just one more video.'

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, offline, stdlib-only (Python 3.13). The output is a single line
of 119 characters.
